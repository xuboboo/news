## 范围与判断依据

本次结合 REA 对当前前端构建产物的静态分析、仓库源码追踪、依赖审计和回归测试开展。REA 分析记录 `ev_d254cba578b5fed3a6933c1334fb902c7b3a3848ccedeaf4ef8781dfb5f2d9c3` 对应的前端构建版本 `12be2df...`；其依赖图不完整，并产生大量通用语法候选项，因此候选数量不作为漏洞数量，也不能据此断言不存在漏洞。下列问题均以源码路径和依赖公告核实后列为有效发现。

## 确认并修复的问题

### 1. 登录后返回地址可被操纵

- **影响：** 未登录访问受保护页面时，应用将当前路径写入登录状态；登录页未校验该路径便跳转。攻击者可构造恶意返回地址，造成登录后跳出站点的开放重定向。
- **修复：** 将 `react-router-dom` 升至 `7.18.4`；新增严格站内路由 allowlist，仅允许本站已知页面及安全的文章/事件详情路径，非法路径统一回到 `/hot`。登录页读取和提交目标时均经过校验。
- **回归：** 新增登录集成用例，覆盖 `//`、反斜杠、绝对 URL 和有效事件详情路径；另有 18 个返回路径单元用例。
- **公告：** [React Router GHSA-wrjc-x8rr-h8h6](https://github.com/advisories/GHSA-wrjc-x8rr-h8h6)。

### 2. Vite 开发服务默认监听所有网卡

- **影响：** `host: true` 使开发/预览服务暴露到所有网络接口；在 Windows 环境中，受影响版本和网络可达条件与 Vite 公告描述的文件泄露风险相符。
- **修复：** Vite 升至 `6.4.3`；开发与预览默认绑定 `127.0.0.1`，只有显式设置 `HOST` 时才改为指定监听地址。
- **公告：** [Vite GHSA-fx2h-pf6j-xcff](https://github.com/advisories/GHSA-fx2h-pf6j-xcff)。

### 3. 前端开发依赖含已公告漏洞

- **影响：** 原锁文件中的 Vite、Vitest、Tailwind/PostCSS 依赖链在 `npm audit` 中报告 15 项问题（5 moderate、8 high、2 critical）。
- **修复：** 升级 Vite、Vitest、Tailwind CSS、PostCSS 插件及 React Router，并重生成 lockfile；迁移 Tailwind v4 的 PostCSS 插件和 CSS 入口配置。

### 4. Python MCP SDK 版本范围允许安装存在漏洞的版本

- **影响：** 原范围 `mcp>=1.0.0,<2` 可解析到低于多个安全修复版本的版本；pip-audit 对已解析版本报告 PYSEC-2026-1617、3482、3483。特定公告的利用前提依部署方式和接口使用情况而异。
- **修复：** 最低版本收紧至 `mcp>=1.28.1,<2`，覆盖上述修复版本；同步将 Pydantic 固定到与当前 MCP SDK 兼容的 `2.11.10`。
- **公告：** [PYSEC-2026-3482](https://osv.dev/vulnerability/PYSEC-2026-3482)。

## 防回归的相邻修复

将 `WxLayoutDetail` 中用于异步过期请求判断的 ref 更新从 render 阶段移到 `useLayoutEffect`，修复 lint 指出的 render 副作用，同时保留路由切换后的过期响应保护。

## 部署及回滚

合并/推送后应重建应用镜像并检查服务健康状态。此版本涉及前端构建依赖和后端 MCP 依赖，没有新增数据库迁移。

```powershell
docker compose up -d --build backend worker ai-worker crawler nginx
docker compose ps
Invoke-WebRequest http://127.0.0.1/api/v2/health
```

生产环境仍须按 [上线检查单](上线检查单.md) 设置 `ENVIRONMENT=production`、HTTPS 下 `COOKIE_SECURE=true`、`ENABLE_DOCS=false`，并核对外层反向代理、防火墙和 `HOST` 配置。开发服务器绑定回环地址只收紧默认监听，不替代生产环境网络边界。

回滚时检出上一个已知正常提交并按仓库上线检查单重新构建应用镜像；本次不含数据库 schema 变更。
