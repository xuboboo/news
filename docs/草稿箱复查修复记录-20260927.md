## 实施和修复后验证

### 实施

- 列表删除成功后为当前筛选发起替代请求；不再只作废请求却留下永久 loading。删除失败只反馈到原筛选，卸载后不再更新页面。
- 列表轮询沿 ID 游标刷新已加载范围，用新响应替换旧分页对象；旧稿完成后更新状态，并从不匹配的状态筛选移除。
- 详情删除核对请求的路由编号和生命周期；换稿、卸载、离页后返回同编号时都忽略旧删除的成功或失败。新稿加载后重置旧操作的忙碌状态。
- 前后端尾注清理识别标题层级，以及反引号/波浪线围栏的字符和长度；来源节内的子标题不会结束清理，围栏内的“声明”不会误删正文。
- 创建接口只接受 JSON 整数编号，拒绝浮点数与布尔值；校验在读取选题、计额度与派发前完成。
- 所有编辑字段与已保存值比较，改回原值恢复“已保存”；备选标题同样处理。
- 状态筛选、编辑/预览、备选标题补充 `aria-pressed`；卡片用 `aria-describedby` 关联状态与摘要/错误，按钮内调整为合法的行内元素。
- 空筛选分别显示“暂无某状态的草稿”，提示切换“全部”。
