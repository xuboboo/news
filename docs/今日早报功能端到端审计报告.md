## 三、发现并修复的事故：第 155 期缺失

**现象**：`daily_report` 表最新一期为 9-15（第 154 期），9-16 整期缺失，期号跳号。

**根因**：早报只依赖每日 08:00 整点的一次 crontab 调度；本地 PC 部署在该时刻
关机/休眠/引擎停摆时 celery 不追赶错过的调度，当天早报永久缺失。告警 webhook
未配置，故无人知晓。

**修复（commit `6821f0d`）**：
- `report_catchup_task`：beat 每小时 :45 触发（避开 08:00 主调度）；
- 缺口判定 `catchup_missing_reports`：历史回看 3 天无行才补（补算不推送）；
  今天过 08:00 截稿仍无行才补（防止不完整窗口顶出当期并误推送）；
- 与主调度靠 advisory lock 幂等，并发安全；集成测试覆盖 07:45/08:45 两个口径。

**执行**：第 155 期已经由 `/admin/report?date=2026-09-16` 正式补生成
（昨夜今晨窗口 48 篇 / 5 事件 / AI 综述，任务记录 success）。
