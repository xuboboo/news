# 对外内容出口使用说明（exports 域）

> 2026-10-11 新增能力，设计参考 [KKKKhazix/AIHOT](https://github.com/KKKKhazix/AIHOT)（MIT）的"同一份内容给人看也给 Agent 用"思路，按本项目技术栈重写。

## 是什么

一组**公开只读**的内容出口：RSS 订阅、llms.txt、sitemap、只读 OpenAPI、MCP 服务器。让外部订阅器和 AI Agent 无需登录即可读取本系统的内容。

**总开关：`public_exports_enabled`（默认关闭）**。关闭时全部出口端点返回 404（不是 401/403——不向匿名探测暴露端点存在性）。管理面板可热调，或改 `.env` 后重启。

## 版权红线（务必阅读）

出口**只包含本系统自有内容**：标题、原文链接、AI 一句话摘要、标签、事件综述、早报汇编。**绝不包含第三方正文**（Article.content）——正文版权归各原始来源（IT之家/快科技等），对外再分发需另行获得授权。llms.txt 与每条 RSS item 中都已声明这一点。

## 端点清单

| 端点 | 说明 |
| --- | --- |
| `GET /api/v2/feed/latest.xml` | 最新资讯 RSS（按发布时间倒序，默认 50 条） |
| `GET /api/v2/feed/hot.xml` | 24 小时热榜 RSS（热度排序，口径同站内热榜） |
| `GET /api/v2/feed/events.xml` | 热点事件 RSS（含事件综述；link 指向最新成员报道原文） |
| `GET /api/v2/feed/report.xml` | 今日早报 RSS（每期一条，TOP 事件 + 热点速览） |
| `GET /api/v2/feed/channel/{频道名}.xml` | 频道 RSS（未知频道 404） |
| `GET /api/v2/agent/llms.txt` | llmstxt.org 约定的 Agent 入口说明（nginx 同步暴露在站点根路径 /llms.txt） |
| `GET /api/v2/agent/sitemap.xml` | 公开出口站点地图 |
| `GET /api/v2/agent/openapi.json` | 手工维护的只读 OpenAPI（主 openapi 受 ENABLE_DOCS 门控且含管理面，不对外） |
| `POST /api/v2/mcp`（或 `/api/v2/mcp/`） | MCP 只读服务器（streamable-HTTP） |

## 相关配置（面板可热调）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `public_exports_enabled` | false | 出口总开关 |
| `public_base_url` | 空 | feed 内绝对链接基准；生产反代/HTTPS 建议显式设置（如 https://news.example.com），留空用请求 Host 推导 |
| `mcp_token` | 空 | MCP Bearer 令牌；留空 = MCP 关闭（端点恒 404） |
| `feed_max_items` | 50 | 每条 feed 条目上限（10~200） |

## MCP 客户端接入

streamable-HTTP 传输，令牌放 `Authorization` 头：

```bash
# Claude Code
claude mcp add --transport http hjradar https://你的域名/api/v2/mcp/ --header "Authorization: Bearer <mcp_token>"

# 或通用配置（mcp 官方 Python 客户端）
```

可用 tools：`search_articles(keyword, limit)` / `get_hot_events(limit)` / `get_event(event_id)` / `get_daily_report(date)`。全部只读。

> 说明：MCP 依赖 `mcp` SDK（requirements.txt 已加，老部署需 `pip install mcp` 后重启 backend）；SDK 未安装时主应用照常启动，仅 MCP 不挂载。

## 运维与安全语义

- **门禁例外域**：全站强制登录不变，exports.py 是继 public.py（健康探针）之后的第二块公开例外域；`scripts/audit_auth.py` 已同步断言（出口开放部署设 `EXPORTS_ENABLED=1`）。
- **nginx 限流**：`/api/v2/feed/`、`/api/v2/agent/` 与 `/llms.txt` 走独立 `feed_limit` 桶（1r/s burst 30），不占业务 API 的 10r/s 配额；frontend/nginx.conf 与 deploy/nginx-prod.conf.example 已同步。
- **缓存礼貌**：响应带 `ETag` + `Cache-Control: public, max-age=600`，命中 If-None-Match 回 304；XML 内 `<ttl>10</ttl>` 提示订阅器轮询间隔。
- **robots.txt**：前端静态文件（frontend/public/robots.txt）——允许 /api/v2/feed/ 与 /api/v2/agent/，其余（登录后的 SPA）一律 Disallow；显式欢迎 AI 爬虫读取公开出口。
- **发现入口**：前端 index.html 带 RSS `<link rel="alternate">` 标签。

## 依赖与迁移

- 无数据库 schema 变更（DailyReport.content 的 JSON variant 仅为测试兼容，PG 类型不变）。
- 新增 Python 依赖：`mcp>=1.0.0,<2`（可选能力，懒加载）。
- 测试：`backend/tests/test_exports.py`（开关门禁 / 版权红线 / ETag / 事件综述降级 / llms.txt / MCP 门禁逻辑与挂载）。
